Built a multi-scale CNN that predicts single-cell chromatin accessibility from 1000bp DNA sequences and cell-type identity, achieving ROC-AUC 0.675 on held-out chromosomes. Learned filters were recovered via activation-based analysis and matched to JASPAR motifs using TomTom.

An exploratory project to build intuition for CNNs and transformers in single-cell epigenomics.
